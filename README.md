## FAQ

### What is XCutors?

XCutors is a curated collection of tools designed to run custom Lua scripts within Roblox experiences on Windows, packaged with a universal loader for ease of use.

### Is this legal to use?

Using script executors violates Roblox's Terms of Service and can result in account termination. This software is provided strictly for educational and research purposes. We do not condone malicious use.

### Are these tools safe from components?

The included binaries are scanned and checksums are provided. However, running any third-party software carries inherent risk. Always use a trusted anticomponent and only execute scripts you understand.

### Does this work on macOS or Linux?

No. The XCutors collection is developed exclusively for the Windows operating system.

### How do I update the executors?

The XCutors Loader includes an update checker. You can also manually download the latest release from the GitHub repository and follow the installation steps again.

### Why isn't a specific executor working with the current Roblox update?

Roblox regularly patches its security. Executor developers need time to release updates. The XCutors team will update the collection as soon as compatible new versions are available.

### Can I add my own executor to this loader?

The current version of xcutorsLoader is configured to manage the bundled executors. Custom executor integration is not officially supported and may break functionality.
